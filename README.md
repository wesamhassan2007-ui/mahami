# متابعة المهام

صفحة لمتابعة مهام الشركات والأقسام، بالعربي، وبتشتغل على الموبايل والكمبيوتر.

- **الأقسام:** معدات الحريق، معدات البناء، مهام المساعدين، بناية نهلة.
- **الصلاحيات:** المدير والمساعد بيشوفوا كل شي. رئيس القسم بيدير قسمه. العامل بيشوف قسمه والمهام المشتركة معه، وبيغيّر الحالة وبيكتب ملاحظات.
- **الدخول:** برقم التلفون وكلمة السر، بدون رسائل SMS.
- **التكلفة:** مجانية بالكامل. GitHub Pages لاستضافة الصفحة، وFirebase على الخطة المجانية (Spark) لحفظ البيانات، بدون بطاقة دفع.

إذا فتحت الصفحة قبل ما تحط إعدادات Firebase، بتشتغل كنسخة تجريبية فيها بيانات وهمية، وبتنحفظ على جهازك بس.

---

## الإعداد (مرة وحدة، حوالي ربع ساعة، والأفضل من كمبيوتر)

### ١. اعمل مشروع Firebase
1. افتح https://console.firebase.google.com وادخل بحساب Google.
2. اضغط **Create a project**، وسمّيه مثلًا `mahami`. بعدها كمّل، وفيك تطفي Google Analytics لأنك مش محتاجه.
3. ضل على الخطة المجانية **Spark**. لا تضغط Upgrade ولا تحط أي بطاقة.

### ٢. فعّل الدخول
1. من القائمة: **Build › Authentication › Get started**.
2. من تبويب **Sign-in method** اختار **Email/Password**، وفعّل أول خيار بس، وبعدها **Save**.
   (الصفحة بتحوّل رقم التلفون لحساب داخلي تلقائيًا، فالموظف ما بيحتاج إيميل.)

### ٣. اعمل قاعدة البيانات
1. من القائمة: **Build › Firestore Database › Create database**.
2. اختار أقرب موقع إلك، مثلًا `europe-west`، واختار **Production mode**.
3. بعد ما تنعمل، روح على تبويب **Rules**، وامسح كل اللي فيه، والصق محتوى ملف `firestore.rules` كامل، واضغط **Publish**.

### ٤. انسخ إعدادات الربط
1. اضغط على الترس ⚙️ جنب **Project Overview**، وبعدها **Project settings**.
2. بأسفل الصفحة، تحت **Your apps**، اضغط على أيقونة الويب `</>`، وسمّي التطبيق `mahami`، واضغط **Register app**. ما بتحتاج Hosting.
3. رح يطلعلك كود فيه `const firebaseConfig = { ... }`. انسخ اللي بين القوسين `{ }`.
4. افتح `index.html` ودوّر على هالسطر:
   ```js
   const FIREBASE_CONFIG = null;
   ```
   وبدّل `null` باللي نسخته، بحيث يصير متل هيك:
   ```js
   const FIREBASE_CONFIG = {
     apiKey: "...",
     authDomain: "....firebaseapp.com",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
   > هاي الإعدادات عادي تكون ظاهرة بالكود. الحماية الفعلية بتجي من كلمات السر وقواعد الصلاحيات بملف `firestore.rules`.

### ٥. ارفع الصفحة على GitHub Pages
1. اعمل repo جديد عام (**Public**)، مثلًا اسمه `mahami`.
2. ارفع عليه `index.html` و`firestore.rules` و`README.md`.
3. من **Settings › Pages**: تحت **Source** اختار **Deploy from a branch**، وبعدها `main` و`/ (root)`، واضغط **Save**.
4. بعد دقيقة أو دقيقتين بيصير رابطك جاهز:
   `https://wesamhassan2007-ui.github.io/mahami/`

### ٦. أول تشغيل
1. افتح الرابط. رح تطلعلك تحت شاشة الدخول خانة **"أول تشغيل: اعمل حساب المدير"**.
2. اكتب اسمك ورقمك وكلمة سر من 6 أحرف أو أرقام أو أكتر. هيك بتكون المدير.
3. **المدير التاني:** من زر **الموظفين** اضغط **موظف جديد**، واكتب اسم المدير التاني ورقمه، واختار الدور **المدير**. المديرين الاتنين إلهم نفس الصلاحيات الكاملة.
4. من زر **الموظفين** كمان ضيف مساعدك ورؤساء الأقسام والعمال. الصفحة بتقترح كلمة سر لكل واحد، وإنت بتبعتله ياها مع الرابط.

## أسئلة شائعة

**موظف نسي كلمة السر؟**
من **الموظفين**، افتح حسابه واكتب كلمة سر جديدة واحفظ. مهامه بتضل متل ما هي.

**موظف ترك الشغل؟**
افتح حسابه واضغط **حذف**. ما بيعود يقدر يدخل، ومهامه بتضل موجودة بدون مسؤول.

**بدي أضيف قسم أو أغيّر أنواع المهام؟**
كلها موجودة بأول الكود تحت `DEPTS` بملف `index.html`.
